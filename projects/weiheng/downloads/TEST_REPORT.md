## 4. 人工审查

- 桌面端 1440px 视觉检查：通过。
- 移动端 390 × 844 视觉检查：通过。
- “示例餐盘”与真实用户餐盘有独立标记。
- 长期记忆待确认、已确认、安全边界三种状态可区分。
- 营养结果使用区间表达，并注明估算局限。
- 空内容触发推荐不会崩溃。
- 记录标题为空会阻止提交。
- 不配置 `VITE_AI_ENDPOINT` 时本地规则正常运行。
- AI 代理未配置服务端密钥时返回 HTTP 503，前端可回退本地规则。
- 手机作品展示页 `/showcase.html`：HTTP 200，390px 视口横向溢出为 0。
