# DDC 2026 报名表项目介绍

## 可直接粘贴版本（约 460 字）

味衡是一个面向日常饮食决策的 AI 辅助产品，源自我此前已有的“饭前决策”构想。它解决的不是记录热量，而是人们在时间、预算、现有食材、口味和健康目标冲突时，仍不知道该吃什么的现实问题。

本次在原有概念与第一版 Demo 基础上完成重构，新增“餐前条件决策—餐后轻量反馈—可审核长期记忆—下一次推荐调整”的闭环。用户可以设置目标、偏好、忌口和准备时间；系统根据当前条件生成含理由、步骤、替代方案和营养区间的一餐卡。餐后只需选择“还想再吃、一般、不太合适”，系统据此生成记忆候选；只有用户确认后，偏好或回避信号才会参与后续排序，并可随时停用。产品明确区分本地规则与真实模型，没有 API 时仍能完整运行，模型密钥只允许放在服务端。

项目已通过生产构建、10 项规则与记忆测试和 24 项 Chrome 端到端检查，完成桌面与移动端截图。我在项目中负责产品问题定义、体验方向、AI 工作流设计、结果审查和迭代推进（具体编程参与度待本人核实）；代码、测试与文档由 AI 编程 Agent 辅助实现。当前仍待本人账号授权完成公开部署，营养数据均为估算，产品不提供医疗建议。

## 30 秒口头介绍

味衡不给你二十个菜谱，而是先理解此刻真正拥有的条件，再给一张能马上执行的一餐卡。吃完后，一次轻量反馈会形成记忆候选；你确认后，它才改变下一次推荐，也可以随时停用。当前 Demo 默认使用透明的本地规则，同时预留了服务端安全接入真实模型的能力。
