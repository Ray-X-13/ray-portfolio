# Frame 产品介绍网页

单文件静态产品官网，无需构建、无需安装依赖。页面包含产品定位、导演模式交互、Take 事件机制、RDK X5 技术链路、20 秒演示、验证目标与产品边界。

## 本地预览

在本目录运行：

```bash
python3 -m http.server 8000
```

打开：

```text
http://localhost:8000
```

## 交互说明

- 拖动“主体位置”，观察构图安全区和跟随方向；
- 切换全身、半身、细节三种画幅；
- 点击“完成一次动作”，生成一个逻辑模拟 Take；
- 点击“模拟遮挡”，查看主体丢失状态；
- 点击“暂停跟随”，验证人工接管反馈。

页面内没有摄像头权限请求，适合直接在群聊和评审设备上打开。

## 事实边界

- 页面是产品概念与交互原型；
- Take 生成来自前端规则模拟；
- 不包含真实人体识别、云台控制或 RDK X5 数据；
- 真机性能、时延与稳定性必须在上板后实测并注明条件。
